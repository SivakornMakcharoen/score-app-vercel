# ระบบกรอกคะแนน (Vercel + Neon Postgres)

```
public/        หน้าเว็บ: index.html + app.js (ผู้ใช้), admin.html + admin.js (Admin)
api/[...path].js   API ทั้งหมด (Vercel Function)
lib/db.js      เชื่อมฐานข้อมูล Postgres และสร้างตารางให้เองอัตโนมัติ
vercel.json    ตั้งค่า + security headers
```

## ขึ้นระบบ (ทำครั้งเดียว ใช้เวลา ~15 นาที)

### 1) ขึ้น GitHub
1. เข้า github.com สร้าง repository ใหม่ (ตั้งเป็น **Private** ก็ได้)
2. กด "uploading an existing file" แล้วลากไฟล์/โฟลเดอร์ทั้งหมดในโปรเจกต์นี้ขึ้นไป (**ไม่ต้องมี node_modules**) แล้ว Commit

### 2) สร้างโปรเจกต์บน Vercel
1. เข้า vercel.com → Sign up ด้วยบัญชี GitHub (เลือกแพลน Hobby ฟรี)
2. **Add New → Project** → เลือก repo ที่เพิ่งสร้าง → Import
3. ตรงช่อง **Environment Variables** เพิ่ม
   - Name: `ADMIN_PASSWORD`  Value: รหัสผ่าน Admin ที่ยาว สุ่ม อย่างน้อย 12 ตัวอักษร
4. ไม่ต้องแก้การตั้งค่าอื่น กด **Deploy** (รอบแรกยังใช้ไม่ได้ เพราะยังไม่มีฐานข้อมูล)

### 3) ต่อฐานข้อมูลฟรี (Neon)
1. ในโปรเจกต์บน Vercel ไปแท็บ **Storage** (หรือ Marketplace) → เลือก **Neon** (Postgres) → Create ด้วยแพลน Free
2. ถ้าเลือกภูมิภาคได้ ให้เลือก **Singapore** (ใกล้ไทยที่สุด)
3. เชื่อมเข้ากับโปรเจกต์นี้ (Connect Project) ระบบจะเพิ่มตัวแปร `DATABASE_URL` ให้เอง
4. ไปแท็บ **Deployments** → กด ⋯ ที่รอบล่าสุด → **Redeploy**

ตารางในฐานข้อมูลจะถูกสร้างอัตโนมัติเมื่อมีคนเรียกใช้ครั้งแรก ไม่ต้องรันคำสั่งอะไร

### 4) ทดสอบ
- เปิดลิงก์ `https://ชื่อโปรเจกต์.vercel.app` (ผู้ใช้) และ `/admin.html` (Admin)
- **เปิดในหน้าต่างไม่ระบุตัวตน (Incognito)** เพื่อเช็กว่าคนทั่วไปเข้าได้โดยไม่ต้องล็อกอิน Vercel
  ถ้ามีหน้าให้ล็อกอิน Vercel ให้ไปที่ Settings → Deployment Protection แล้วปิดสำหรับ Production
- ลองกรอกคะแนน 1 รายการ แล้วดูในหน้า Admin

### 5) ตั้งชื่อลิงก์ให้สวย (ไม่บังคับ)
Settings → Domains → แก้ชื่อโปรเจกต์ หรือเพิ่มโดเมนของตัวเองทีหลังได้ ลิงก์ `.vercel.app` ถาวร ไม่เปลี่ยน

## การใช้งาน Admin
- เข้า `/admin.html` ใส่รหัส ดูอันดับ **แก้ไขคะแนน** ลบรายการ และ Export CSV
- แถวสีเหลืองคือรายการที่ควรตรวจ (จำนวนสูงผิดปกติ หรือ ABO ซ้ำ)
- ลบรายการแล้ว คนนั้นกรอกใหม่ได้อีกครั้ง
- เปลี่ยนรหัส Admin: Vercel → Settings → Environment Variables → แก้ `ADMIN_PASSWORD` แล้ว Redeploy

## สิ่งที่ระบบกันไว้ให้
- เซิร์ฟเวอร์ตรวจทุกค่า (จำนวนเต็ม 0-200, ABO 4 หลัก, ชื่อไม่มีอักขระอันตราย) และคำนวณคะแนนรวมเอง
- ส่งซ้ำไม่ได้ (ชื่อเล่น + ABO ไม่ซ้ำ ไม่สนตัวพิมพ์เล็ก/ใหญ่) บังคับที่ฐานข้อมูล
- จำกัด 60 ครั้ง/นาที/IP และล็อกอิน Admin ผิดเกิน 5 ครั้งใน 15 นาทีถูกล็อกชั่วคราว (นับใน DB ใช้ได้จริงบน serverless)
- เซสชัน Admin เก็บเฉพาะ hash ใน DB อยู่ 8 ชั่วโมง กดออกจากระบบแล้วใช้ต่อไม่ได้
- cookie HttpOnly + SameSite=Strict + Secure, Content-Security-Policy, HTTPS ตลอด

## ข้อจำกัดที่ควรรู้
- แพลน Hobby ของ Vercel ใช้ได้เฉพาะโปรเจกต์ส่วนตัว/ไม่ใช่เชิงพาณิชย์ (ตามเงื่อนไข Vercel)
- ระบบตรวจ "ความจริง" ของจำนวนที่กรอกไม่ได้ และคนที่รู้ชื่อเล่น + ABO ของคนอื่นก็กรอกแทนได้
- เวอร์ชันนี้ไม่มีระบบ "รายชื่อผู้มีสิทธิ์" (ทุกคนที่มีลิงก์กรอกได้)
- ข้อมูลจากเวอร์ชันเก่า (SQLite) ไม่ย้ายมาอัตโนมัติ
- กด Export CSV สำรองข้อมูลก่อน/หลังกิจกรรม
